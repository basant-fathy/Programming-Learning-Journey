# 11 - OOP as It Should Be (Applications)

This course moves from OOP concepts to **real application design**.  
It focuses on building complete systems using proper OOP structure, reusable components, and clean architecture.

This is where OOP becomes practical engineering, not theory.

---

## 📘 Course Overview

During this course, I applied OOP principles to design and build complete, scalable applications.

The focus is on structuring large systems, separating responsibilities, and extending software safely without breaking existing code.

---

## 🧠 What I Learned

Throughout this course, I learned how to:

- Design full applications using OOP
- Build reusable libraries and components
- Apply encapsulation, abstraction, inheritance, and polymorphism in real code
- Structure large systems with clear responsibilities
- Apply validation, permissions, logging, and basic security rules
- Extend systems without modifying core logic

---

## 🛠 Projects & Applications (C++)

This course is fully project-based and progressive.  
Projects evolve like real software systems.

- 💻 **Utility Library Project**
- 💻 **Input & Validation Library Project**
- 🏦 **Complete Bank System**, including:
  - Users & permissions
  - Login & security
  - Logs & auditing
  - Multiple system extensions
- 💱 **Currency Exchange System**
- Practical use of interfaces and abstract classes

These projects reflect how real applications grow and evolve over time.

---

## 🎯 Final Outcome

By the end of this course, I am able to:

- Build real-world applications using OOP
- Structure large codebases confidently
- Extend systems safely and cleanly
- Read and understand professional OOP-based systems
